# جزوه کامل: محاسبه پارامترهای آموزش‌پذیر در شبکه‌های عصبی (MLP)
**درس:** رایانش عصبی و یادگیری عمیق  

---

## ۱. تعریف دقیق پارامتر آموزش‌پذیر (Trainable Parameter)
در یک شبکه عصبی دو دسته متغیر داریم:
1. **Hyperparameters (ابرپارامترها):** مقادیری که طراح دستی تعیین می‌کند و شبکه یاد نمی‌گیرد (مثل تعداد لایه‌ها، نرخ یادگیری $\eta$، اندازه بچ).
2. **Trainable Parameters (پارامترهای آموزش‌پذیر):** مقادیری که با گرادیان نزولی و پس‌انتشار خطا (Backprop) مقدارشان بهینه می‌شود:
   $$\text{Trainable Params} = \text{وزن‌ها (Weights)} + \text{بایاس‌ها (Biases)}$$

---

## ۲. فرمول ریاضی لایه پیش‌خور (Fully Connected / Dense)

معادله یک لایه عصبی:
$$z = W \cdot x + b$$
$$a = \sigma(z)$$

اگر لایه ورودی دارای $n_{in}$ نرون و لایه خروجی دارای $n_{out}$ نرون باشد:
- **ماتریس وزن‌ها ($W$):** ابعاد آن برابر $n_{out} \times n_{in}$ است. چون هر نرون ورودی به همه نرون‌های خروجی وصل است:
  $$\text{تعداد وزن‌ها} = n_{in} \times n_{out}$$
- **بردار بایاس ($b$):** به ازای هر نرون در لایه خروجی، دقیقاً یک بایاس اضافه می‌شود:
  $$\text{تعداد بایاس‌ها} = n_{out}$$

### فرمول نهایی یک لایه:
$$\boxed{\text{Params} = (n_{in} \times n_{out}) + n_{out} = n_{out} \times (n_{in} + 1)}$$

> **نکته امتحانی (لایه بدون بایاس):** اگر در صورت مسئله ذکر شود `bias=False` یا «بدون بایاس»، بردار $b$ حذف شده و فرمول برابر است با:
> $$\text{Params} = n_{in} \times n_{out}$$

---

## ۳. بررسی اثر توابع فعال‌ساز (Activation Functions)

توابع فعال‌ساز برای شکستن خطی‌بودن و ایجاد نگاشت غیرخطی بعد از تبدیل افاین اعمال می‌شوند:

### الف) توابع بدون پارامتر (تعداد پارامتر = ۰)
اکثر توابع استاندارد صرفاً یک تابع ریاضی قطعی المان‌به‌المان هستند و **هیچ وزنی یاد نمی‌گیرند**:
- **ReLU:** $f(x) = \max(0, x) \to \mathbf{0}$
- **Sigmoid:** $f(x) = \frac{1}{1 + e^{-x}} \to \mathbf{0}$
- **Tanh:** $f(x) = \tanh(x) \to \mathbf{0}$
- **Leaky ReLU:** $f(x) = \max(\alpha x, x)$ با شیب ثابت $\alpha=0.01 \to \mathbf{0}$
- **Softmax:** $f(x_i) = \frac{e^{x_i}}{\sum e^{x_j}} \to \mathbf{0}$
- **GELU / ELU:** با ضریب ثابت $\to \mathbf{0}$

### ب) استثنای امتحانی: فعال‌سازهای پارامتریک
- **PReLU (Parametric ReLU):** شیب ناحیه منفی ($\alpha$) یک متغیر آموزش‌پذیر است.
  - حالت پیش‌فرض (تک‌متغیره): **۱ پارامتر**
  - حالت کانال‌محور: **$n_{out}$ پارامتر**

---

## ۴. جدول مرجع تمام لایه‌ها و اجزای جانبی

| نام لایه / جزء | تعداد پارامتر آموزش‌پذیر | توضیحات تکمیلی |
| :--- | :---: | :--- |
| **Input Layer** | **۰** | لایه ورودی صرفاً ویژگی‌های داده را نگه می‌دارد. |
| **Linear (Dense)** | $(n_{in} \times n_{out}) + n_{out}$ | وزن تمام اتصالات + یک بایاس به ازای هر نرون خروجی. |
| **Linear (bias=False)** | $n_{in} \times n_{out}$ | بدون بردار بایاس. |
| **Dropout** | **۰** | مکانیزم کاهش بیش‌برازش؛ هیچ وزن یا بایاسی ندارد. |
| **BatchNorm1d** | **$2 \times n_{out}$** | دو پارامتر یادگیری مقیاس ($\gamma$) و جابه‌جایی ($\beta$). میانگین و واریانس بافر آماری هستند و گرادیان نمی‌گیرند. |
| **LayerNorm** | **$2 \times n_{out}$** | مشابه بچ‌نرم دارای وزن مقیاس و شیفت است. |

## ۵. مثال‌های حل‌شده امتحانی

### مثال ۱: مسئله کلاسی چندلایه
شبکه‌ای با بردار ورودی اندازه **۸**، لایه پنهان اول **۱۶** (ReLU)، لایه پنهان دوم **۳۲** (Tanh) و خروجی **۴** (Softmax) مفروض است:

1. **لایه اول ($8 \to 16$):**
   - وزن: $8 \times 16 = 128$
   - بایاس: $16$
   - جمع لایه اول: $128 + 16 = \mathbf{144}$

2. **لایه دوم ($16 \to 32$):**
   - وزن: $16 \times 32 = 512$
   - بایاس: $32$
   - جمع لایه دوم: $512 + 32 = \mathbf{544}$

3. **لایه خروجی ($32 \to 4$):**
   - وزن: $32 \times 4 = 128$
   - بایاس: $4$
   - جمع لایه خروجی: $128 + 4 = \mathbf{132}$

$$\text{مجموع کل پارامترها} = 144 + 544 + 132 = \mathbf{820}$$

---

### مثال ۲: تله تستی با لایه بدون بایاس
شبکه با ابعاد `[10, 20, 5]` که لایه اول بایاس دارد اما لایه دوم `bias=False` است:
- لایه اول: $(10 \times 20) + 20 = 220$
- لایه دوم: $20 \times 5 = 100$
- کل پارامترها: $220 + 100 = \mathbf{320}$

---

## ۶. تحلیل حافظه و فضای مصرفی مدل (دقت FP32)

هر عدد اعشاری استاندارد (Float32) برابر با **۴ بایت** است.

1. **حافظه مدل (استنتاج / ذخیره روی هارد):**
   $$\text{حجم بر حسب بایت} = \text{کل پارامترها} \times 4$$
   $$\text{حجم بر حسب کیلوبایت} = \frac{\text{کل پارامترها} \times 4}{1024}$$

2. **حافظه مورد نیاز در فاز آموزش با بهینه‌ساز Adam:**
   در حین آموزش به ازای هر پارامتر:
   - ۴ بایت: مقدار پارامتر ($W$ یا $b$)
   - ۴ بایت: گرادیان پارامتر ($\nabla W$)
   - ۴ بایت: ممان اول در آدام ($m$)
   - ۴ بایت: ممان دوم در آدام ($v$)
   $$\text{حافظه آموزش Adam} \approx \text{کل پارامترها} \times 16 \text{ بایت}$$
   *(در بهینه‌ساز SGD ساده با مومنتوم این ضریب برابر با ۱۲ بایت است).*
